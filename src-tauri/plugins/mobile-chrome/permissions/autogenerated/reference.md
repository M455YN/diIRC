## Default Permission

Allow native mobile chrome tab bar commands

#### This default permission set includes the following:

- `allow-configure-tab-bar`
- `allow-set-tab-bar-selected`
- `allow-set-tab-bar-visible`
- `allow-get-tab-bar-insets`
